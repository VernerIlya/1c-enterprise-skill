---

## 📌 Зачем нужен этот скилл?

Разработка конфигураций 1С через текстовые исходники (для версионирования в Git, сборки в CI/CD или генерации с помощью автономных нейросетевых агентов) сопряжена с десятками неочевидных ограничений платформы 1С. 

Обычные ИИ-модели систематически совершают фатальные ошибки: путают теги форм, вызывают серверные функции на тонком клиенте, ломают индексы SQL или генерируют невалидный манифест выгрузки `ConfigDumpInfo.xml`, из-за чего Конфигуратор выдает ошибку **«Отсутствует контейнер метаданных»**.

**Этот скилл решает данную проблему на 100%**, предоставляя:
1. Исчерпывающий свод правил схемы метаданных 1С 8.3.
2. Автоматический валидатор перед коммитом (`validate_config.py`).
3. Детерминированный генератор манифеста (`generate_config_dump_info.py`).
4. Быстрый генератор чистых проектов 1С (`init_project.py`).
5. Готовые эталонные шаблоны объектов метаданных (`templates/`).

## 🚫 Топ-8 фатальных ошибок при генерации 1С и их решения

| № | Ошибка платформы 1С | Причина у новичков / нейросетей | Инженерное решение скилла |
| :-: | :--- | :--- | :--- |
| **1** | `Свойство DefaultForm не входит в состав Document / Attribute` | Документы в 1С используют свойство `<DefaultObjectForm>`, а `<DefaultForm>` допустим **только** для обработок и отчетов. | Строгое разделение: документам назначается `<DefaultObjectForm>Document.<Имя>.Form.ФормаДокумента</DefaultObjectForm>`. |
| **2** | `Свойство ExtendedPresentation не входит в состав Form` | Попытка скопировать свойства обычных объектов метаданных в дескриптор формы `Forms/<Имя>.xml`. | Из файла метаданных формы полностью исключен тег `<ExtendedPresentation/>`. |
| **3** | `Свойство Use не входит в состав Attribute` | Тег `<Use>ForItem</Use>` разрешен **только** для справочников. В реквизитах документов и табличных частей он запрещен. | Линтер проверяет контекст каждого реквизита и удаляет лишние теги. |
| **4** | `Ошибка СУБД: попытка включить в индекс поля TEXT, NTEXT, IMAGE` | Измерения регистров с типом `xs:string` без указания длины становятся `NVARCHAR(MAX)` в SQL и ломают уникальный индекс `_AccumRgTn`. | Все строковые измерения регистров получают строгие квалификаторы: `<Length>50</Length>` и `<AllowedLength>Variable</AllowedLength>`. |
| **5** | `Процедура или функция не определена (ТекущаяДатаСеанса)` | Вызов даты или функций начала периода (`НачалоМесяца`, `КонецДня`) внутри контекста тонкого клиента `&НаКлиенте`. | Вся работа с датами и запросами изолирована в серверных методах `&НаСервере`. |
| **6** | `Отсутствует контейнер метаданных` | Ошибочный корневой тег `<DumpInfo>` вместо `<ConfigDumpInfo format="Hierarchical">`, либо отсутствие маркера `UTF-8 BOM (\xef\xbb\xbf)`. | Генератор манифеста пишет точный заголовок, а все файлы автоматически сохраняются в `utf-8-sig`. |

## ⚡ Быстрый старт (Quickstart)

### 1. Создание новой конфигурации с нуля за 1 команду
```bash
python scripts/init_project.py "C:/MyConfigs/MyNewERP" "Моя_Новая_ERP"
```
Скрипт создаст полноценную валидную структуру проекта с русским языком, правильными ContainedObject-контейнерами и `ConfigDumpInfo.xml`.

### 2. Проверка готовой конфигурации (Zero-Error Guarantee)
Перед тем как загружать конфигурацию в Конфигуратор 1С, запустите линтер:
```bash
python scripts/validate_config.py "C:/Path/To/Your/1C_Configuration"
```
*Линтер проверит XML-синтаксис, запрещенные теги, квалификаторы чисел, контексты процедур BSL и манифест. При наличии ошибок выведет точный файл и строку.*

### 3. Автоматическое обновление ConfigDumpInfo.xml
Если вы добавили или изменили объекты, документы, реквизиты или формы:
```bash
python scripts/generate_config_dump_info.py "C:/Path/To/Your/1C_Configuration"
```

### 4. Загрузка в 1С:Предприятие
1. Запустите **Конфигуратор** (пустую или целевую базу).
2. Выберите в меню: **Конфигурация ➔ Открыть конфигурацию** (если закрыта).
3. Выберите: **Конфигурация ➔ Загрузить конфигурацию из файлов...**
4. Укажите папку с вашей конфигурацией.
5. Нажмите **F7** (Обновить конфигурацию базы данных) и подтвердите изменения (**Принять**).
6. Нажмите **F5** — конфигурация запустится в режиме управляемого приложения!

## 🤖 Использование с AI-агентами (Antigravity, Claude, Cursor)

Данный скилл полностью совместим со стандартом **Antigravity Skills**:
- Скопируйте папку `1c-enterprise-skill` в `~/.gemini/config/skills/1c-enterprise-skill`.
- Теперь любой агент автоматически активирует скилл при запросах по 1С:Предприятию 8.3, разработке конфигураций, BSL-скриптам или устранению ошибок выгрузки.

## 🚀 Релиз v2.0.0 (Enterprise Resilience & POS Styling)

В версию **2.0.0** вошли важнейшие архитектурные обновления, основанные на решении реальных производственных сценариев:
- 🖨️ **Правило 13 (Печатные формы и чеки):** побеждено размножение текста на диапазонах ячеек (`.Объединить()`). Добавлен стандарт компактного кассового чека (термолента POS 58/80 мм на 2 колонки).
- 📦 **Правило 14 (Устойчивость проведения):** ликвидирована системная ошибка `[ОшибкаХранимыхДанных]`. Внедрена связка `ОбработкаЗаполнения` (автоподстановка реквизитов при создании) + умная обработка проведения.
- 🚗 **Правило 15 (Сквозная фильтрация и подбор по VIN):** реализация динамического отбора в формах выбора (`НачалоВыбора` + `Отбор.Ссылка`), автоподбора при вводе текста (`АвтоПодбор`) и реактивной фильтрации каталога в Рабочем месте кассира.
- 🛡️ **Контроль UTF-8 BOM:** строгая защита от дублирования маркера кодировки (`Double BOM Trap`).
